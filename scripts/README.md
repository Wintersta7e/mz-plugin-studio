# Scripts

`.github/workflows/ci.yml` runs every one of these; run them locally directly or through the npm scripts named below (`npm run check` runs the local ones).

- `scripts/check-coverage.mjs` — run by `npm run test:coverage` and `npm run test:golden:coverage`; checks that coverage reports every tracked source file and that each directory, or each golden-covered generator file, is at or above its floor
- `scripts/check-golden-commits.mjs` — `node scripts/check-golden-commits.mjs <base>..<head>`, or `--github-event` to take the range from a GitHub Actions event; checks that commits changing `src/` add no golden file or case, test-only commits delete no golden line, and user-visible golden changes carry a `CHANGELOG.md` change unless the commit is test-only and only adds whole cases (in a JSON golden, only adds lines)
- `scripts/ci-policy.mjs` — `package <app.asar>` checks the packaged app's top-level entries, licence files and `node_modules/` size; `runtime-deps` (`npm run ci:runtime-deps`) checks that `dependencies` lists exactly the packages the main process and preload import; `toolchain [--electron]` (`npm run ci:toolchain`) checks that Node, `@types/node` and, with `--electron`, the Node inside Electron match `package.json` `engines`; `needs` checks that every job in `NEEDS_JSON` succeeded; `osv-ignores` checks that each `osv-scanner.toml` entry has an id, a reason and an `ignoreUntil` at most 90 days ahead; `fuses <executable>` checks that the packaged executable's Electron fuse wire holds the states the app requires.
- `scripts/third-party-licenses.mjs` — `npm run licenses` after any lockfile change rewrites `THIRD_PARTY_LICENSES.md`; `npm run licenses -- --check` fails when it is stale.
