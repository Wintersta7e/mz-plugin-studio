# Scripts

`.github/workflows/ci.yml` runs every one of these except those marked as run by hand; run them locally directly or through the npm scripts named below (`npm run check` runs the local ones).

- `scripts/check-coverage.mjs` — run by `npm run test:coverage` and `npm run test:golden:coverage`; checks that coverage reports every tracked source file, that every source file with lines belongs to a floor directory, that each directory is at or above its line and branch floors, and that each golden-covered generator file is at or above its line floor, with the floors `ratchets.json` holds under `coverage`; prints, for every floor, `floor <scope> <metric>: measured X%, floor Y%, slack Z%`, and fails a floor that sits a whole point or more below its measured value, printing the floor to write in `ratchets.json` (each floor is the measured value rounded down); fails without `ratchets.json` or on a floor that is not a whole number
- `scripts/check-ratchets.mjs` — `npm run ratchets`, run by `npm run check` and CI's static job; compares every ratchet with its value at the base commit (CI names it in `RATCHETS_BASE`: the pushed range's base, empty for the merge-base with `origin/main`; locally the merge-base with `origin/main`, else HEAD's parent; `--base <ref>` runs this comparison alone) — each number in `ratchets.json` (`jscpd` ceilings, `coverage` floors) and each `package.json` script's `--at-least` floor and `--max-warnings` ceiling — prints `ratchets: compared N against <sha>`, and fails a ceiling that rose, a floor that fell, a ratchet that vanished, a number outside those sections, an unreadable base or a comparison of nothing (a ratchet new since the base passes; a floor keyed by a suite directory or golden file whose path was renamed since the base is compared under its new key, and one whose path was deleted is dropped, printing `ratchets: dropped <key> (path deleted)`); then runs jscpd under `.jscpd.json` with a JSON report, prints its files scanned, clones, duplicated lines and share against the `jscpd` ceilings in `ratchets.json`, and fails when the clones or duplicated lines are not exactly at their ceilings (a rise prints each clone as `file:start-end ↔ file:start-end`, a fall names the ceiling to write), when a ceiling is missing, or when the run wrote no report or scanned no file, printing how it ended and its last lines
- `scripts/check-golden-commits.mjs` — `node scripts/check-golden-commits.mjs <base>..<head>`, or `--github-event` to take the range from a GitHub Actions event; checks that commits changing `src/` add no golden file or case, test-only commits delete no golden line, and user-visible golden changes carry a `CHANGELOG.md` change unless the commit is test-only and only adds whole cases (in a JSON golden, only adds lines); and that each commit's subject is at most 72 characters and its only trailer is `Co-Authored-By:` naming an allowed co-author, read from the whole body: a hyphenated `Some-Key:` line in any paragraph counts, as does every line of a last paragraph made only of `Key: value` lines (dependency-update bot commits are counted as skipped: in a pull request only when the bot opened it, elsewhere only when the hosting service committed them)
- `scripts/ci-policy.mjs` — `package <app.asar>` checks the packaged app's top-level entries, licence files, and `out/` and `node_modules/` sizes against their budgets (constants in the script, raised only in a commit that says why), printing each size with its budget; `runtime-deps` (`npm run ci:runtime-deps`) checks that `dependencies` lists exactly the packages the main process and preload import; `toolchain [--electron]` (`npm run ci:toolchain`) checks that Node, `@types/node` and, with `--electron`, the Node inside Electron match `package.json` `engines`; `needs` checks that every job in `NEEDS_JSON` succeeded; `diff-coverage <lcov.info> <diff-cover.json>` (CI's unit job, after diff-cover's 90 % floor) prints the lcov report's source files and the changed lines diff-cover measured, and fails when the lcov report is missing or lists no source file (coverage did not run) or the diff-cover report holds no line count — 0 measured lines with coverage present passes as a change with no executable line; `codeql <sarif-dir>` (CI's codeql job) prints each result's rule and `file:line` and `codeql: files N, runs N, results N`, and fails on any result, on a directory without a SARIF file, or on a SARIF file without a run or a results list; `osv-ignores` checks that each `osv-scanner.toml` entry has an id, a reason and an `ignoreUntil` at most 90 days ahead; `fuses <executable>` checks that the packaged executable's Electron fuse wire holds the states the app requires.
- `scripts/e2e-prepare.mjs` — `npm run e2e:prepare` and CI; builds the unpacked release (`npm run e2e:prepare -- --reuse` reuses one present, for a build made earlier in the same job, as the Windows CI and release jobs do), writes the inspect-enabled copy and `dist/e2e-artifacts.json`, fails unless that fuse is the only difference or if a script the renderer page loads at start holds the code editor, read from the source map the minified renderer build writes beside each script (left out of the package), or has no such map, or if the start scripts together outgrow their budget; prints each start script's bytes, sources and code editor sources, then their sum against the budget
- `scripts/e2e-visual-update.mjs` — `npm run e2e:visual:update [-- --check]`, run by hand; runs the visual project inside the pinned image and copies back only the Linux baselines
- `scripts/knip-scanned.mjs` — a knip reporter that `npm run knip` and `npm run knip:production` add to print how many files the run analysed; it fails a run that analysed none
- `scripts/mutation.mjs` — `npm run mutation -- --since <base>`, run by `.github/workflows/mutation.yml` weekly on the week's changes and by hand on a branch's changes since `origin/main` (not part of `npm run check`: a run takes minutes per changed file); mutates every `src/**/*.{ts,tsx}` file changed between the base and HEAD under `stryker.config.json`, its sandbox in the OS temp directory, with `MUTATION_TESTING=1` so `vitest.config.ts` leaves out the tests that parse a source module's own statements; prints `mutation: no src change` and exits 0 when no such file changed, else prints `mutating N files, mutants M`, and fails when the score falls under the config's `thresholds.break` or when the changed files hold no mutant (a run that tested nothing)
- `scripts/typecov.mjs` — `npm run typecov`, run by `npm run check` and CI's static job; runs the `npm run typecov:<program>` script of every program the root `tsconfig.json` references, half the available cores at a time (each script fails below 100 % with `--at-least 100`), prints each program's `(covered / total) pct%` and `typecov programs N`, and fails when a run fails, prints no summary or counts no identifier, or when no program is referenced, printing how a failed run ended and its last lines
- `scripts/third-party-licenses.mjs` — `npm run licenses` after any lockfile change rewrites `THIRD_PARTY_LICENSES.md`; `npm run licenses -- --check` fails when it is stale; `--sbom <file>` (the release workflow's build job) writes the same packages, one component per installed version with its npm package URL, license and lockfile hash, as a CycloneDX 1.6 JSON bill of materials instead, printing `sbom components N`.
